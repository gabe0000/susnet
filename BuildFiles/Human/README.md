# Human Builder Notes

Use this folder for human-facing notes, checklists, and procedures. Keep high-level steps, physical setup, and operational reminders here. Technical agent playbooks live under `BuildFiles/Agents/`.

Suggested contents:
- Setup/teardown steps for radios, power, and networking.
- How to run the web UI, AllStar/DVSwitch basics, and where to find logs.
- Safety reminders (power, antennas, regulatory).
