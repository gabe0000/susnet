# ChirpStack Module

Purpose:
- LoRaWAN network server module for SusNet Next.

Included components:
- `chirpstack`
- `chirpstack-gateway-bridge`
- `redis`
- `postgres`
- `mosquitto`

Default URL:
- `http://<pi-ip>:8081`

Config files:
- `services/chirpstack/config/chirpstack.toml`
- `services/chirpstack/config/chirpstack-gateway-bridge.toml`
- `services/chirpstack/config/mosquitto.conf`
