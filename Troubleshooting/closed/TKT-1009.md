# TKT-1009 - Tts Error

- Date opened: 2025-12-14
- Date closed: 2025-12-15
- Subsystem: Meshtastic
- Severity: high
- Status: closed

## Summary
Text to speech call out the node number instead of the node long name. We have the long name posting everywhere else that I can think of, but this still uses the note number please also check to see if anywhere else will accidentally populate the note number instead of the name.

## Resolution
TTS now maps !node IDs to long names via mesh topology; if a name is missing it speaks “unknown node” rather than the raw ID. Deployed in susnet_api.py and services restarted.
