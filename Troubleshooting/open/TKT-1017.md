# TKT-1017 – Meshtastic channel pills show generic names (Primary/Secondary) instead of actual channel names

- **Status:** open  
- **Severity:** medium  
- **Subsystem:** Meshtastic UI (message feed / channel mapping)  
- **Opened:** 2025-12-17  
- **Opened by:** Codex  

## Summary
In the Meshtastic UI, channel pills and related labels in the message feed are showing generic names like “Primary” / “Secondary” instead of the actual channel names (e.g., MuhQuail, MCRG256). Two prior tickets (1015/1016) described the same issue; they are consolidated here.

## Evidence
- User report from Tag & Create: channel name should be the real channel (e.g., MuhQuail or MCRG256), but the UI renders “Primary/Secondary”.
- Applies both to the message entry “Channel” selector/pill and the message feed channel pill.

## Impact
- Hard to know which channel a message was sent/received on; can mis-route or misinterpret messages.

## Next Steps
1) Fix channel mapping in message feed rendering to use actual channel names (from channel details / dropdown list), not positional labels.  
2) Ensure send-channel selector and displayed pills are consistent with the real channel names used in dropdowns.  
3) Regression check: DMs should continue to show “DM” and avoid channel pills.
