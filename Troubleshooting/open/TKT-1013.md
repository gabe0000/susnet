# TKT-1013 – GMRS HTTPS registration TLS CN mismatch

- **Status:** open  
- **Severity:** medium  
- **Subsystem:** AllStar GMRS HTTP registration  
- **Opened:** 2025-12-17  
- **Opened by:** Codex  

## Summary
`res_rpt_http_registrations` is failing HTTPS registration to `https://join.gmrshub.com/` for node 531121 because the certificate CN/SAN does not match the hostname. This spams warnings and the GMRS HTTP registration never completes.

## Evidence
- `/etc/asterisk/rpt_http_registrations.conf` currently registers 66190 and 531121.  
- Logs: `SSL: no alternative certificate subject name matches target host name 'join.gmrshub.com'` followed by `Failed to curl URL 'https://join.gmrshub.com/'`.

## Impact
- GMRS HTTP registration for 531121 fails; repeated log noise. IAX registrations remain unaffected.

## Ideas / Next Steps
1) Switch this registration to plain HTTP if allowed by the GMRS service (e.g., `http://join.gmrshub.com/`) to bypass TLS validation.  
2) If HTTPS is required, use a host with a matching cert or request a valid certificate for `join.gmrshub.com`.  
3) Optionally suppress TLS verify for this specific registration (if acceptable) until a correct cert is in place.
